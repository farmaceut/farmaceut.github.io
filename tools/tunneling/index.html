Tunneling correction calculator

Tunneling correction κ(T) for hydrogen / proton transfer. Enter the barrier, the reaction energy and the imaginary frequency; everything is computed in your browser.

Thermal tunneling corrections κ(T) for hydrogen/proton transfer from a one-dimensional barrier model: Wigner, truncated parabola, Eckart, a static MEP-based path model (ZCT-MEP) and the two Eckart-calibrated path corrections ZCT-EC and EQ-FREQ, compared with a numerically exact solution of the one-dimensional Schrödinger equation. Everything is computed in your browser; no data are uploaded.

Barrier parameters

I have energies of reactants, TS and products instead

Same level of theory, electronic energy + zero-point energy (Gaussian: “Sum of electronic and zero-point Energies”). For several species write a sum with spaces: -155.1234 + -76.4321. V₁ = E(TS) − E(reactants), ΔE = E(products) − E(reactants). Free energies (ΔG‡, ΔGrxn) are not the right input.

V₂ = V₁ − ΔE is the reverse barrier. V₁ and ΔE must be measured from the same reference state (reactant or pre-reactive complex) and include zero-point energy. The result is the tunneling correction κ only, not a rate constant.

Exact one-dimensional reference on model profiles with the same V₁, V₂, |ν‡|

Each profile is built so that its maximum is V₁ above the reactant asymptote, its reverse barrier is V₂ and its top curvature gives |ν‡| (mass 1 amu, x in Å). The exact κ(T) of the profile and the path-based models evaluated on the same profile are then compared with the three-number models.

Isotope

One-dimensional mass scaling on the same potential (Q = κlight/κheavy, tunneling contribution only; no zero-point or partition-function terms).

Reaction path V(s)

Drop files here or choose them: ORCA *_IRC_Full_trj.xyz (or _IRC_B_trj.xyz + _IRC_F_trj.xyz), a Gaussian IRC output .log/.out, or a two-column table (s, V).

ORCA: the energy is read from the comment line of each frame and the mass-weighted arc length is built from the geometries (Kabsch alignment). Gaussian: the “Summary of reaction path following” table (RxCoord in bohr·amu1/2). Files stay on your computer.

Rescaling to a different V₁ multiplies V by c = V₁/Vtop and s by √c (the curvature is kept); ΔE is scaled by the same factor. Use ZPE-corrected energies of the stationary points whenever possible.

Definitions

Energies are measured from the reactant asymptote (or pre-reactive complex); ΔE = Eprod − Ereact, V₂ = V₁ − ΔE. With P(E) the one-dimensional transmission probability and β = 1/kBT:

κ(T) = β eβV₁ ∫E₀∞ P(E) e−βE dE,   E₀ = max(0, ΔE)

u‡ = hc|ν‡|/kBT, Tc = hc|ν‡|/2πkB = 0.2290·|ν‡| K per cm⁻¹. The sub-barrier share is fsub = ∫E₀V₁P e−βEdE / ∫E₀∞P e−βEdE. The equivalent free-energy shift is |ΔΔG‡| = RT |ln(κ₁/κ₂)|: the conversion of a ratio of two tunneling corrections into energy units. It is not an error of the computed activation free energy.

Implemented models

  • Wigner: κ = 1 + (u‡)²/24. Uses |ν‡| only; a low-u‡ expansion (conventionally u‡ ≲ 2, |ν‡| ≲ 414 cm⁻¹ at 298 K).
  • Truncated parabola (Skodje–Truhlar closed form), with r = u‡/2π and V′ = min(V₁, V₂): κ = πr/sin(πr) − r/(1−r)·exp[(1−1/r)V′/kBT] for r < 1, and r/(r−1)·{exp[(1−1/r)V′/kBT] − 1} for r > 1.
  • Eckart (Brown parametrisation; transmission in the logarithmic domain; thermal integral to (E − V₁)/kBT = 60). Fixed by (V₁, V₂, |ν‡|). A symmetric variant (V₂ := V₁) is also shown.
  • ZCT-MEP: static MEP-based path model on V(s): θ(E) = Cθ∫√(V − E) ds between the turning points (Cθ = 4.55495 for kcal/mol, Å, amu), P = [1 + e2θ]⁻¹ (Kemble form) or min(1, e−2θ) (plain WKB), parabolic continuation above the top. No vibrationally adiabatic potential, no corner cutting. Despite the name it is not claimed to reproduce every ZCT variant of the literature.
  • ZCT-EC (this work): κZCT-MEP[path] · κEckart(V₁, V₂, ν‡) / κZCT-MEP[Eckart(V₁, V₂, ν‡)].
  • EQ-FREQ (this work): solve κZCT-MEP[Eckart(V₁, V₂, νeff)] = κZCT-MEP[path] at each temperature (Brent), then κ = κEckart(V₁, V₂, νeff(T)).
  • Exact 1D reference: Riccati/transfer-matrix propagation with exact cosh/sinh steps, Richardson extrapolation in the step, thermal integral with a square-root substitution at E₀.

Literature semiclassical theories (Advanced mode, model profiles)

For the model profiles the page also evaluates published one-dimensional semiclassical theories, using the equations of the original papers (a different kind of input than ZCT-EC: they need the action S(E) or the derivatives V₂…V₈ at the barrier top, which are exact for the closed-form profiles and not available from a tabulated IRC):

  • standard instanton (Miller/Affleck) and the uniform instanton, USIT with and without the high-energy correction — S. Upadhyayula, E. Pollak, J. Phys. Chem. Lett. 14, 9892 (2023);
  • mVPT2 and mYF (ℏ² theory) — Upadhyayula, Pollak, J. Phys. Chem. A 128, 3434 (2024);
  • SVPT2, SVPT4 and modified SVPT4 (ℏ⁴ theory) — Pollak, Upadhyayula, J. Chem. Phys. 160, 184110 (2024).;
  • exact-WKB transmission P = 1/(1+exp(W/ħ)) with W = W₀ + ħ²W₂ (+ ħ⁴W₄) — J. E. Lawrence, J. Chem. Phys. 163, 234119 (2025), eqs 4.1, 4.8, 4.9, B1 (one-dimensional part of the framework). The loop integrals are evaluated numerically on an ellipse in the complex plane, which needs V, V′, V″ at complex coordinates (complex jets of the closed-form profiles); above the top W₀, W₂, W₄ are continued by their quadratic Taylor polynomials.

Checks against the papers: USIT Table 1 (all four columns, all temperatures), SVPT4 Tables I–III to the printed digits (≤ 3·10⁻⁶), mVPT2/mYF Table 2 (≤ 0.1 %, one entry 0.6 %), the coefficients G₀…Z against Appendix B. Lawrence: the loop integrals reproduce his closed form W₂ₙ for the asymmetric Eckart barrier (eq 4.11) to 10⁻⁹ and the ħ-expansion coefficients of the exact transmission of a Gaussian barrier (W₂ to 10⁻⁴, W₄ to 5 %); on the Eckart barrier κ is within 10⁻³ (ħ²) and 2·10⁻³ (ħ⁴) of the exact value; this page agrees with the Python package to 4·10⁻³ % on six model profiles (test python_agreement_lawrence). The modified SVPT4 uses constants U₃₁, U₄₁ that were derived from the conditions of the paper's Sec. III.B instead of being copied from its eq 3.22; it reproduces Tables I–III to 10⁻⁴ (up to 10⁻³ at u = 20). Taylor coefficients V₃…V₈ are taken from the closed-form profile by power-series arithmetic. Where a theory is undefined (standard instanton above its crossover temperature, SVPT4 with Z < 0) the table shows “—”.

Not implemented: SCT/LCT/μOMT (in one dimension without reaction-path curvature they reduce to ZCT; the curvature terms need the multidimensional reaction-path Hamiltonian, which a V(s) table does not contain), ring-polymer instanton and RPMD (dynamical methods that need the full-dimensional potential), the multidimensional parts of Lawrence’s framework (ħ² instanton corrections in many dimensions, sphaleron rate above the crossover, anharmonic Wigner correction; its one-dimensional O(ħ²) and O(ħ⁴) expressions are implemented above). These are different observables or need multidimensional input; no superiority over them is claimed. The calibrations ZCT-EC and EQ-FREQ were tested only on smooth single-humped one-dimensional profiles. On the manuscript benchmark (Sect. 4.4: 648 cases from 270 model profiles, κexact ≥ 2) the modified Yasumori–Fueki variant is comparable to ZCT-EC/EQ-FREQ in the median but has a larger worst case (1.44 against 1.14/1.11 on the development families), the ħ⁴ series (SVPT4, mSVPT4 and Lawrence ħ⁴) are often undefined or unreliable and do not improve the worst case for strongly curved barriers (ħω/V₁ ≳ 0.5), the exact-WKB ħ² transmission of Lawrence is of the same quality as mYF (median 1.00, worst 1.41 on the development families), and USIT is biased low like ZCT-MEP; these statistics hold for smooth single-humped model profiles only and the higher-order theories need derivatives at the barrier top, which a tabulated IRC does not provide.

How to read the results

  • Matched profiles with the same (V₁, V₂, |ν‡|) can have different exact κ: the three numbers do not determine κ. In the manuscript the spread at 298.15 K for V₁ = 12, V₂ = 20, 1800 cm⁻¹ is a factor of 2.6.
  • The exact solver is exact only for the one-dimensional Hamiltonian. It does not account for corner cutting, transverse zero-point-energy variation or other multidimensional effects.
  • Path option: V(s) of an IRC enters ZCT-MEP/ZCT-EC/EQ-FREQ as it is. If the path has an intermediate minimum (well), resonances can matter and the exact 1D reference may not converge; the page warns when it detects such a feature. Flat tops (|ν‡| undefined) are not covered.
  • The exact solver on a user path pads the path with constant potential at both ends; IRC end points that are not asymptotes make this a model assumption.
  • Barrier heights and |ν‡| depend on the electronic-structure method; the page propagates what you type. A ±10 % change of |ν‡| changes the Eckart κ at 298 K by tens of percent (see the sensitivity panels).

Relation to the Python package

The Python package of the article is the reference implementation for all results in the paper. This page re-implements the equations of the manuscript for interactive use. What it reproduces and what it does not:

  • Reproduced here: the closed-form models (Wigner, truncated parabola, Eckart), the exact 1D reference, ZCT-MEP, ZCT-EC and EQ-FREQ on matched model profiles (Table 2, five families, button above), the double-hump case, and the CH₄ + OH• example.
  • Python only: the 540-case benchmark, bootstrap and Clopper–Pearson intervals, literature cases, mass and isotope scans, parameter maps, the real-IRC analysis and the Hessian-based isotope analysis.
  • Numerical differences to the Python code: cubic spline with natural end conditions (SciPy’s default is not-a-knot), a dense path grid of 8001 points (Python: 20001), barrier top refined by a parabola through the three highest grid points (Python: grid maximum), Gauss–Chebyshev quadrature of the WKB action between turning points (Python: trapezoid rule on the grid), an analytic action for the Eckart reference in ZCT-EC/EQ-FREQ (Python: a discrete 801-point model path), and a transfer-matrix propagator with Richardson extrapolation in ln T for the exact solver (Python: Riccati log-derivative, Richardson in T). For isotopologues of a model profile the whole potential, including the product-side step, is scaled with the mass (the same Cartesian potential); the Python isotope scan keeps the step width fixed at 0.6 Å·amu½ for both isotopes.
  • Measured agreement (all 1224 profile–temperature cases of the Python benchmark that this page can build: Gaussian, Lorentzian, sech², sech⁴, Lorentzian², shoulder and the double-hump family with separation 2.4 w; 200–600 K): exact κ agrees to ≤ 0.01 % (double-hump set ≤ 0.09 %), Wigner, truncated parabola and Eckart to ≤ 0.03 %, ZCT-MEP, ZCT-EC and EQ-FREQ to ≤ 0.03 % (double-hump set ≤ 0.8 %, where the action integral passes the intermediate minimum), νeff to ≤ 0.24 %, the plain-WKB variant of ZCT-MEP to ≤ 0.5 %. The semiclassical methods agree on 1170 cases to ≤ 0.03 % (instanton, USIT, mVPT2, mYF, SVPT2, mSVPT4, Lawrence ħ² and ħ⁴) and to ≤ 0.3 % (SVPT4); for mSVPT4 the cases without a result and the “usable” criterion (modification of the potential ≤ 50 %) are identical in all 1170 cases. For an ORCA trajectory the parsers give the same s(V) and the same ZCT-MEP κ to six digits when the same atomic masses are used. Reference values and the scripts that produced them are in the Python package repository.
  • Atomic masses for ORCA files: this page uses the most abundant isotopes by default (what ORCA and Gaussian use in the IRC), the Python package uses standard atomic weights (e.g. C 12.0107). For a CH3-type path the arc length then differs by up to 0.1 %, κ by 0.03–0.1 % in the example; the selector in the “Reaction path” tab switches between the two.
